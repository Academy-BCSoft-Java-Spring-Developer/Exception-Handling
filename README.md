# Java Exception Handling Practice

This repository contains hands-on exercises designed to master exception handling mechanisms in Java.

## Exercises Overview

- esercizio_1: ClassCastException and autoboxing
- esercizio_2: NullPointerException on uninitialized array
- esercizio_3: NullPointerException on String method dereferencing
- esercizio_4: ArrayIndexOutOfBoundsException handling
- esercizio_5: Custom checked exception (PersonalException) for subtraction validation
- esercizio_6: Custom checked exception (DivisioneException) for division by zero
- esercizio_7: Interactive Scanner input validation with printStackTrace
